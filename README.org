* Overview

Cross-platform dotfiles that bring the =dwm= keyboard workflow to both
Linux (native =dwm=) and macOS (=AeroSpace= + =Karabiner= + =Hammerspoon=
+ =Raycast=).

Same chords, same muscle memory, same workspaces — regardless of OS.

** Philosophy

- Keyboard-driven, mouse-optional.
- =Super= (Caps Lock on macOS via Karabiner; =Mod4= on Linux) is the
  single modifier prefix.
- Emacs-first: =emacsclient= is =$EDITOR=, =org-mode= for agenda + capture
  + roam.
- Configuration is text, lives in git, syncs across machines.
- Private overrides live in a separate submodule so the public repo
  stays shareable.

* Key Bindings

All bindings use =Super= (Caps Lock tap = =Escape= on macOS).

| =Super+Shift+1..9=     | Send window to workspace 1..9           |
| =Super+g= / =;=        | Previous / next workspace               |
| =Super+Tab=            | Last workspace                          |
| =Super+f=              | Fullscreen                              |
| =Super+Shift+Space=    | Toggle floating                         |
| =Super+q=              | Close window                            |
| =Super+'=              | Scratchpad terminal                     |
| =Super+`=              | Unicode / emoji picker                  |
| =Super+Backspace=      | System action menu (sysact)             |
| =Super+w=              | Browser                                 |
| =Super+e=              | Emacs                                   |

* Installation

** macOS

#+begin_src zsh
git clone --recurse-submodules https://github.com/alkhaldieid/dotfiles.git ~/dotfiles
cd ~/dotfiles
./bootstrap.sh
#+end_src

The bootstrap script will:

1. Install Homebrew + dependencies from =Brewfile=.
2. Apply macOS defaults (=scripts/macos-defaults.sh=).
3. Stow all relevant config packages.
4. Install the Emacs daemon =LaunchAgent=.
5. Print a post-install checklist.

*** Post-install manual steps

These cannot be automated (Apple requires GUI consent):

1. *System Settings → Privacy & Security → Accessibility* — enable
   =AeroSpace=, =Karabiner-Elements=, =Hammerspoon=, =Raycast=.
2. *System Settings → Privacy & Security → Input Monitoring* — enable
   =karabiner_grabber= and =karabiner_observer=.
3. Open =Karabiner-Elements= → *Complex Modifications* → *Add rule* —
   enable:
   - "Caps Lock → Ctrl+Opt+Cmd; tap → Escape"
   - "Fn → Input Source Switch"
4. Open =Raycast= → *Settings → General* — set hotkey to
   =Ctrl+Opt+Cmd+D=.
5. Open =Hammerspoon= → *Preferences* — enable "Launch at login" and
   install the command-line tool.

** Linux (Arch)

#+begin_src bash
git clone --recurse-submodules https://github.com/alkhaldieid/dotfiles.git ~/dotfiles
cd ~/dotfiles
./bootstrap.sh
#+end_src

The script will:

1. =pacman -S --needed - < arch-packages.txt=
2. Build =dwm= and =dwmblocks= from =stow/dwm/= and =stow/dwmblocks/=.
3. Stow all configs.
4. Enable the user-level =emacs.service= via =systemctl --user=.

** Private submodule

Machine-specific or sensitive configs live in =./private/=, which is
a separate private repository (=dotfiles-private=).

#+begin_src zsh
git submodule update --init --recursive
#+end_src

Set up SSH access to the private repo first, or the submodule init
will fail.

* Customization

** Per-machine overrides

Put machine-specific tweaks in =./private/machine-overrides/<hostname>/=
and source them from =stow/zsh/.zshrc.local=.

** Adding a keybinding

1. Add to =stow/aerospace/.config/aerospace/aerospace.toml= (macOS).
2. Add equivalent to =stow/dwm/.local/src/dwm/config.h= (Linux).
3. =aerospace reload-config= or rebuild dwm.

* Troubleshooting

** macOS: nothing happens when I press Super+key

#+begin_src zsh
pgrep -lf AeroSpace
pgrep -lf karabiner
aerospace reload-config 2>&1
open -a "Karabiner-EventViewer"
#+end_src

Hold Caps Lock + tap a key. You should see
=left_control left_option left_command <key>=. If you only see
=caps_lock=, the Karabiner rule isn't enabled.

** Config won't reload

Check for duplicate bindings:

#+begin_src zsh
grep -n '^ctrl-alt-cmd-' ~/.config/aerospace/aerospace.toml | \
  awk -F= '{print $1}' | sort | uniq -d
#+end_src
